## What the evidence does not show

- CM-6: Checks the AppArmor annotation only. The securityContext.appArmorProfile field (Kubernetes 1.30 and later) is not checked, so a pod can set an unconfined profile there and still pass; CM-6 evidence does not cover that field.
- AC-17(400): Evidences that only the designated administrator group holds cluster-admin. It cannot show where that group's identities connect from; the dedicated administration workstation itself (SI-400) needs configuration review.
- CM-2: Supporting evidence only: an image tagged latest leaves the baseline configuration undefined, but pinned tags alone do not make a baseline.
